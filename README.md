# Flask Learning Log

Daily progress log while learning Flask from scratch, working toward a portfolio project called **GitHub Wrapped** — a Spotify-Wrapped-style stats dashboard for any GitHub username.

This repo tracks the *learning* process (routes, templates, styling, etc.) day by day. It's not the final polished project — that'll live in a separate repo once it's ready to demo.

## Roadmap

- [x] Day 1 — Flask basics: app object, routes, `debug=True`, control flow
- [x] Day 2 — Dynamic routes, URL parameters, query strings
- [x] Day 3 — Jinja templates: `render_template()`, variables, loops/conditionals
- [x] Day 4 — Template inheritance (`base.html`, `{% block %}`)
- [x] Day 5 — Static files (CSS + JS) via `static/` and `url_for()`, dark-themed styling
- [ ] Day 6 — Site skeleton: homepage input form + results page
- [ ] Day 7-9 — GitHub API integration
- [ ] Day 10-11 — Data visualization with Chart.js
- [ ] Day 12-14 — Polish, error handling, deployment prep

## Stack

Flask · Jinja2 · HTML/CSS · JavaScript · Chart.js (upcoming) · GitHub API (upcoming)
